# Holtmail

A self-hosted email archiver. Holtmail connects to your mail accounts over IMAP and JMAP, keeps every message exactly as it was received, and gives you fast full-text search and a quiet web interface to read your archive.

No open core, no enterprise edition: every feature, SSO included, is in this repository under one license.

Status: design. See the plan in [docs/PLAN.md](docs/PLAN.md).
